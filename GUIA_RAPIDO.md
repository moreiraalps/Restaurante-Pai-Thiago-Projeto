## ⚠️ AÇÃO NECESSÁRIA: Configurar Banco de Dados

Para o sistema funcionar completamente, você precisa executar o SQL no Supabase:

### Passo 1: Acessar o SQL Editor do Supabase
Clique neste link (ou copie e cole no navegador):
```
https://supabase.com/dashboard/project/gxrdmnjvazoxlyudczmx/sql/new
```

### Passo 2: Copiar o SQL
Abra o arquivo `supabase_setup.sql` (está na pasta /app do projeto)

### Passo 3: Colar e Executar
1. Copie TODO o conteúdo do arquivo `supabase_setup.sql`
2. Cole no editor SQL do Supabase
3. Clique no botão **RUN** (ou aperte Ctrl+Enter)

### Passo 4: Confirmar
Você verá uma mensagem de sucesso. Agora o banco está pronto! 🎉
